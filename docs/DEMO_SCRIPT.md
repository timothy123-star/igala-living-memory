# Igala Living Memory — 60–90 Second Demo

Open `http://localhost:3000`.

“Igala Living Memory addresses a practical preservation problem: oral language material can be collected without its context, contributor control, or reliable provenance. This prototype keeps all three together.”

“This is a live record from the archive: *Igala Proverbs*, contributed by speaker Ojonugwa. The source card shows its language, format, context, consent state, and provenance. Notice that the original audio is deliberately private. The current consent permits recording, storage, transcription, translation, and human review—but not public distribution.”

“Below, the record keeps the human workflow visible. Ojima-Ojo is attributed as transcriber, Yalo is attributed for the English interpretation, and Project Owner is the reviewer. We can read the 14 human-confirmed Igala proverb lines beside the English text. Crucially, the interface says the English text is caption-aligned to the source video, not an independently verified translation from the audio.”

“Finally, this is our Muse Spark learning panel. This contribution is approved and the speaker’s written consent extension explicitly allows AI processing and educational publication. When I generate, Muse Spark creates a source-referenced lesson from the approved archive material. It uses the human-confirmed Igala text and caption-aligned English interpretation, states what the archive cannot establish, and is always labelled AI-generated—not human-verified.”

“Igala Living Memory makes responsible AI useful only when the community’s evidence and permissions support it.”
